# Game Design Notes

## Current playable question

Does a small hidden-state economy create policy choices with delayed, context-sensitive consequences?

The Phase 1 sandbox exposes hidden state on purpose. Once the directional behavior is trusted, later phases should hide these values and force inference through releases, advisers, and narrative feedback.

## Deliberately excluded

No advisers, voting, persuasion, media, political pressure, events, exploration, campaign progression, cutscenes, audio, or legacy scoring are implemented in this iteration.

## Evaluation principle

Before adding content, verify that rate paths produce understandable trade-offs rather than one universally dominant move.
